## 用例 A — 注册登录

步骤：

1. POST `/api/auth/register`
2. POST `/api/auth/login`
3. GET `/api/auth/me`

输入：

```json
{ "username": "alice", "password": "pw123" }
```

输出：register/login 返回 `ok: true` 和用户；me 返回 `username = alice`。

结果：通过（`test_register_login_me`）。

---

## 用例 B — 创建题目并另存新版本（添加题目 / 版本）

步骤：

1. 登录 alice
2. POST `/api/questions` 创建单选题「你的性别」
3. POST `/api/questions/{id}/versions`，题干改成「你的生理性别」
4. GET 旧 id，确认旧题干没变

输入（创建）：

```json
{
  "type": "single",
  "stem": "你的性别",
  "options": ["男", "女", "其他"],
  "category": "人口统计"
}
```

输出：第一版 `version=1`；第二版 `version=2`，`derived_from` 等于第一版 id，`logical_id` 相同；旧文档 stem 仍是「你的性别」。

结果：通过（`test_create_question_and_new_version`）。

## 用例 C — 创建问卷并添加题目

步骤：

1. 登录 owner，创建性别 / 年龄 / 水果三道题
2. POST `/api/surveys`，标题「新生调查」，`allow_multiple: true`
3. POST `/api/surveys/{id}/items` 挂上 q1/q2/q3

输入（items）：

```json
{
  "items": [
    { "item_id": "q1", "question_id": "<性别题id>", "required": true },
    { "item_id": "q2", "question_id": "<年龄题id>", "required": true },
    { "item_id": "q3", "question_id": "<水果题id>", "required": true }
  ]
}
```

输出：问卷 `status=draft`，items 长度为 3。

结果：通过（包含在 `test_jump_validate_submit_and_stats` 前半段）。

## 用例 D — 跳转逻辑

前置：问卷规则「q1 选男 → 跳到 q3」（跳过年龄）。发布后换 bob 登录填写。

输入（提交）：

```json
{
  "answers": [
    { "item_id": "q1", "value": "男" },
    { "item_id": "q3", "value": ["苹果"] }
  ]
}
```

输出：HTTP 200，答卷保存。路径上没有 q2，不要求填年龄。

结果：通过。

结果：通过（`test_share_and_usage_and_cross_stats`）。

## 用例 H — 恢复旧版本（阶段二）

步骤：

1. alice 创建单选「你的性别」（v1，选项男/女）
2. 另存 v2：题干改「你的生理性别」，选项加「其他」
3. POST `/api/questions/{v1-id}/restore`

输入（创建 v1）：

```json
{ "type": "single", "stem": "你的性别", "options": ["男", "女"] }
```

输入（另存 v2）：`{ "stem": "你的生理性别", "options": ["男", "女", "其他"] }`

输入（恢复）：无请求体，路径参数为 v1 的 id。

输出：生成 v3，`stem` 回到「你的性别」、选项回到男/女；`restored_from = v1 id`，`derived_from = v2 id`（版本链不断）；v1 文档原文不变。再对 v3 调 restore 返回 400（最新版无需恢复）。

结果：通过（`test_restore_version`）。

## 用例 I — 族级使用查询（阶段二）

步骤：

1. owner 建数字题 v1，A卷引用 v1
2. 另存 v2，B卷引用 v2
3. GET `/api/questions/{id}/usage?scope=family`；再调不带 scope 的旧口径对比

输入：数字题 `{ "type": "number", "stem": "年龄", "validation": { "integer": true, "min": 0, "max": 120 } }`；
A卷 items `[{ "item_id": "q1", "question_id": "<v1 id>", "required": true }]`；B卷同样但填 v2 的 id。

输出：family 返回 2 份问卷，`versions_used` 分别为 `[1]`、`[2]`；旧口径只返回 A卷 1 份。

结果：通过（`test_family_usage`）。

---

## 用例 J — 族级跨卷统计（阶段二）

步骤：用例 I 基础上两卷发布，A卷提交 20、B卷提交 40。

输入（A卷）：`{ "answers": [{ "item_id": "q1", "value": 20 }] }`
输入（B卷）：`{ "answers": [{ "item_id": "q1", "value": 40 }] }`

输出：`stats?scope=family` 聚合 `avg = 30`，`by_version` 里 v1 `avg = 20`；不带 scope 的旧口径 `avg = 20` 不变。

结果：通过（`test_family_cross_stats`）。

## 用例 K — 题库按族取最新版 + 移出/加入（阶段二）

步骤：建文本题，连续另存到 v3；查 `/api/questions?scope=bank`；POST `/api/questions/{id}/bank` `{in_bank:false}` 再 `{in_bank:true}`。

输入：`{ "type": "text", "stem": "自我介绍" }`；另存 v2 `{ "stem": "自我介绍 v2" }`、v3 `{ "stem": "自我介绍 v3" }`；
题库开关请求体 `{ "in_bank": false }` / `{ "in_bank": true }`。

输出：bank 列表该族只出现 v3 一条；移出后整族消失，重新加入后回来。

结果：通过（`test_bank_latest_and_toggle`）。
